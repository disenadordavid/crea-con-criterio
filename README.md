# Crea con criterio — perfil de Instagram (prototipo)

Recreación de la interfaz de Instagram hecha en HTML, CSS y JavaScript para la
asignatura **Entornos Virtuales**.

- Perfil simulado: `@crea.con.criterio`
- 5 publicaciones de feed y 3 historias, con las piezas y los copys de la parrilla
  de contenido original.
- Interfaz navegable: publicaciones, me gusta, comentarios, historias, seguidores.
- Se adapta a escritorio y móvil.
- Un solo archivo, sin servidor, sin base de datos y sin conexión a Instagram.

Proyecto académico. No está afiliado a Instagram ni a Meta.
